## 1. 목적 · 경계

승인이 필요한 실력치 재설정(이상 대응 · Qual 후 재산정 · 상한 초과)을 **적용하기 전에** 과거 wafer로 replay해서 **오탐(가성알람)을 줄이나** 를 채점하는 **순수 함수**다. **미탐(진짜 이상 놓침)은 판정 기준이 애매해 섀도 단계에선 채점하지 않는다**(§4 — 재설정 캡 + 사후 Qual·지연 라벨이 담당). 상한 내 정기 자동 재설정은 섀도 없이 즉시 적용이라 **대상 밖**(트리거는 호출자 — 합의안 A5).

- **경계(포함)** = **순수 점수 계산만** (오탐 감소만).
- **이월** = 트리거 게이팅(`needs_approval` 판정) · 결과 DB 영속 · 발행 · 실제 적용 · 사후 검증(지연 라벨 · 섀도 감시) · 다중 그룹 취합.

## 3. 처리 흐름 — `evaluate_shadow(...) -> dict`

```
evaluate_shadow(
    old_limits, new_limits,       # 구/신 관리선 (Nelson limits dict). 신=호출자가 current row에 proposal delta 오버레이(limit_version·method 등 current 승계 — §5 계약, 🟠)
    points: list[Point],          # replay 30장 (호출자 집계·시간순, 단일 그룹)
    cfg,                          # ShadowConfig — A5/A6 (wafers·pass 임계)
    *, group_key,
) -> dict:
  points = sorted(points, key=lambda p: p.timestamp)             # 방어 정렬(ISO 문자열=시간순, stable) — Nelson stateful 안전 (Review#4)
  old_flagged = _replay_flagged(old_limits, points, group_key, cfg)   # 위반 wafer 수 (구)
  new_flagged = _replay_flagged(new_limits, points, group_key, cfg)   #             (신)
  reduction = 0.0 if old_flagged == 0 else (old_flagged - new_flagged) / old_flagged * 100
  verdict = _verdict(reduction, cfg, measurable=(old_flagged > 0))
  return {
    "group_key": group_key, "n_wafers": len(points),
    "false_alarm_reduction_pct": round(reduction, 1),
    "old_violating_wafers": old_flagged, "new_violating_wafers": new_flagged,
    "verdict": verdict,                  # PASS / FAIL / UNKNOWN
  }

def _replay_flagged(limits, points, group_key, cfg) -> int: # 결정 3-④
  """구/신 관리선으로 순차 replay → 위반 낸 distinct wafer 수.
  Nelson stateful(순차 룰: N2 9연속 등)이라 한 엔진에 시간순 feed. 관리선별 새 엔진(state 격리).
  active_rules 기본=RULES(전체 룰 — 결정 3-①). time_gap_hours는 cfg 주입(hermetic 테스트;
  미주입 시 config 로드). feed는 항상 list 반환([]=위반없음, None 아님) → truthy 체크 안전 (Review#1)."""
  eng = NelsonEngine(limits, whitelist={group_key}, time_gap_hours=cfg.time_gap_hours)
  return len({p.wafer_id for p in points if eng.feed(p)})    # 단일 그룹=wafer당 1 point → set=위반 wafer 수

def _verdict(reduction, cfg, measurable) -> str:           # 결정 5 (파생 — 오탐만)
  if not measurable: return "UNKNOWN"                        # 구=0 → 감소율 정의 불가 → 유보 (결정3, 🟡)
  return "PASS" if reduction >= cfg.reduction_min_pct else "FAIL"
```

- **엣지**: `구=0`(원래 알람 없음) → reduction 정의 불가 → **verdict UNKNOWN**(판정 유보, 🟡). `신>구`(재설정이 알람 늘림) → 음수 reduction → 임계 미달(FAIL).
- **stateful 주의**: `feed`는 순차 상태 축적이라 points를 **시간순**으로 넣어야 하고(위 방어 정렬로 가드), 구/신은 **각각 새 NelsonEngine**(상태 격리). replay 구간 wafer 간 간격이 `time_gap` 임계를 넘으면 상태 리셋 · **윈도우 내 `pm_count`·`limit_version` 불변** 필요(변하면 feed가 버퍼 clear(`:146`)/리베이스라인(`:152`) → 카운트 왜곡) → **연속 구간 권장**(호출자, 🟡).

## 4. 미탐 미채점 결정 (2026-07-22 확정)

**미탐(진짜 이상을 놓침)은 섀도 평가에서 채점하지 않는다 — 오탐 감소만 판정한다.**

**근거**: "진짜 미탐"의 판정 기준(정답 소스)이 애매·불확실하다 — 실제 불량은 결과가 지연돼(지연 라벨) 사전 통계로 완결할 수 없고, 구조적 근사(캡 위반 수 등)는 실제 미탐과 등가가 아니다. 불확실한 지표로 verdict를 흔들기보다 **확실한 오탐 감소만** 판정한다.

**미탐 안전성은 다른 층이 담당** (섀도가 안 봐도 안전한 이유):
- **재설정 캡** (B4-3, `reset_delta_max_sigma` ≤1σ) — 한계를 위험하게 넓히지 못하도록 이미 상한.
- **사후 검증** — Qual 2지표(B5-2) + 지연 라벨(`fdc.actual` 실측 C65) + 섀도 감시(합의안 B6)로 실제 미탐을 사후 포착.

→ `missed_fn` seam·`missed_detection` 출력 필드·미탐 verdict 분기 **전부 제거**. verdict는 오탐 감소율만으로 PASS/FAIL/UNKNOWN.

## 5. 재사용 / 신규

**재사용 (무수정)**
- `nelson_engine.NelsonEngine(limits, whitelist)` · `.feed(point) -> list` · `Point`(**6필드 default 없음**: `group_key`·`wafer_id`·`timestamp`·`value`·`pm_count`·`limit_version` — fixture 전부 채워야 함, 🟡).
- config 로더(A5/A6) · (호출자 측) `recalc_engine` 제안 → limits 매핑 · D0-2/B5-2 Point 생성 로직.

**신규 (`shadow_eval.py`)**
- `evaluate_shadow(...)` · `_replay_flagged(...)` · `_verdict(...)`.
- **`new_limits` 계약**(호출자 🟠): `current` row에 proposal `new_center/ucl/lcl/sigma` **오버레이** → `{center, sigma, ucl, lcl, limit_version, method}`. `limit_version`·`method`는 **current 승계**(proposal엔 없음). `_make_violation`이 `limit_version`을 무조건 읽으므로(`nelson_engine.py:232`) 누락 시 신 관리선 위반에서 KeyError.
- `ShadowConfig` — `params.yaml` 키 속성 **명시 매핑**(2-섹션 로드 · AttributeError 방지 🔴):
  `reduction_min_pct` ← **`limit_engine`**`.shadow_pass_false_alarm_reduction_min_pct`(35.0) · `n_wafers` ← **`limit_engine`**`.shadow_eval_wafers`(30) · `time_gap_hours` ← **`spc`**`.time_gap_threshold_hours`. *(`shadow_pass_missed_detection_max`는 미채점이라 미로드 — params 키 자체는 존치.)*
