> ### ⚠️ `provisional_k` — 실측 필수 (구현만으로 확정 불가)
> 광폭 배수는 **반드시 실 데이터/Scorecard로 튜닝**해야 한다. 문서(사이클_정의:127·Context_Score:116)가 **"4~5σ" 범위만** 주고 값을 안 박은 이유가 이것 — **너무 좁으면(3σ) 과도 폭주, 너무 넓으면 진짜 이상 미탐**이라, **실제 과도 구간 분산**에 값이 좌우된다. 스펙은 **기본 5(보수적 시작)** 로 두되, **"미탐 0 유지 하에 과도 폭주 최소"** 기준으로 시나리오/Scorecard 실측 확정한다(context_score 31 threshold와 동일 방식 — "값을 방어하지 않고 검증·조정 체계를 방어"). **실측 없이 4/5 임의 확정 금지.**
>
> ### 🔬 1차 검증 결과 (2026-07-22, train + sim 시나리오)
> B6-3-a 실제 코드(`_make_provisional`+`NelsonEngine`)로 요란 시나리오(`qual_loud_ch4`: C17 −37.7 레벨 계단)를 재현·측정.
> - **✅ 동작 검증** — 진짜 좁은 센서 **C17 step4(실 baseline σ=2.05)** 요란 **−18σ** 이사: 옛 밴드 **100/100 폭주** → **provisional(k=5) 밴드 4/100 억제**. 재중심(새 중심)이라 wafer가 밴드 중앙 → 억제 성립.
> - **✅ "좁은 센서 별도 처리" 가설 기각** — 밴드가 새 중심으로 **재중심화**하므로 wafer가 밴드 **중앙**에 위치, **σ 폭과 무관**하게 담긴다. 시나리오상 C17은 `level_shifts_eng`(정착 레벨 계단)이라 감쇠 아님. (train aggregate에서 본 "C17 58σ"는 비라벨 데이터의 실제 excursion 오염 — 정상 과도 아님.) → **per-sensor k·특별 처리 불요.**
> - **⚠️ 미확정 = 상한(미탐)** — 위는 **하한(폭주 억제, 너무 좁지 않음)** 검증. 하한은 넓은 k 범위(3·4·5…)가 모두 만족하므로 **5를 고유 확정하지 않는다.** "너무 넓지 않은가(미탐)" 상한은 **주입 이상 라벨 필요 → W7 Scorecard(8/4~5) 확정.** M3(7/30) 요란 관통에서 1차 read.
> - **결론**: `provisional_k=5` = **유효한 시작값(동작·구조 검증 완료)**, 최종값은 미탐 상한(Scorecard) 후 값만 교체(C8 선례).

## 3. 처리 흐름 — `ProvisionalMode` (순수 상태머신)

```
class ProvisionalMode:
  # 상태(결정 1·c): chamber → {phase, post_pm_count, verdict, boundary, last_pm_count}
  #   + last_wafer_id(인메모리 wafer 중복 가드 — 재시작 시 최대 ±1 오차 허용, 미영속)
  #   복구(restore): phase←control_limits(provisional 활성) · verdict는 provisional-활성이 loud 함의(quals=PASS/FAIL이라 직접 복구 X) · post_pm_count만 파생불가→최소영속
  # _phase0_center[chamber][gk]: Phase 0 새-레짐 러닝 중심(바운드) — new_center 자체 산출(G: QualVerdictConfirmed엔 center 필드 없음)
  # _provisional_chambers: set — set_excluded가 "집합 통째 교체"(tttm:126)라 union 유지 (Review B)
  # 부작용 주입: writer(provisional write)·reload·tttm(set_excluded)·persist/load

  on_pm(chamber, pm_count):                 # ② pm_count↑ 감지 (멱등 — Review1)
      if pm_count <= last_pm_count[chamber]: return   # 중복·과거 재전달 무시 (at-least-once → Phase1 카운터 리셋 방지)
      last_pm_count[chamber] = pm_count
      phase[chamber] = PHASE_0             # 억제 (get_phase로 노출)
      post_pm_count[chamber] = 0
      _phase0_center[chamber].clear()      # 새 레짐 중심 버퍼 리셋
      _persist(chamber)

  on_qual_verdict(chamber, verdict):        # ② 주입 (계약 §8-B QualVerdictConfirmed — ★엔지니어 승인 하류, 1-1 정합)
      if phase[chamber] != PHASE_0: return          # 멱등·phase 가드 — 중복 verdict·오상태 무시 (Review F, on_pm과 대칭)
      if verdict == "quiet":                # ★계약 enum "quiet"/"loud" (조용/요란 라벨 아님 — API_Contract §8-B)
          boundary[chamber] = A7_QUIET(10)  # 과도 제외 경계(정보) — 실제 제외는 b
          phase[chamber] = NORMAL           # provisional 미진입, 복귀
      elif verdict == "loud":
          boundary[chamber] = A7_LOUD(1000)
          limits = _make_provisional(chamber)      # ③ 광폭 생성 (Phase 0 버퍼로 중심 산출)
          writer.write_provisional(limits)  # 주입 — 그룹별 version bump + 활성행 deactivate + INSERT (Review D)
          reload()                          # 엔진 반영 (B5-1a seam) — version 변경→Nelson/TTTM _rebaseline(zones 재계산, 버퍼 유지) 유도
          _provisional_chambers.add(chamber)
          tttm.set_excluded(_provisional_chambers)   # ★ 전체 집합 전달 (Review B — 교체 시맨틱, 이전 제외 챔버 보존)
          phase[chamber] = PHASE_1
      _persist(chamber)

  on_wafer(chamber, wafer_id, points):      # ★wafer 단위 1회 호출 (그룹 point 여럿 동반)
      # ★A7 경계(1,000)는 wafer 수 — point마다 세면 그룹수배 과다카운트. wafer_id 경계로 1회만 증가.
      if wafer_id == last_wafer_id[chamber]: return   # 같은 wafer 중복 유입 방지
      last_wafer_id[chamber] = wafer_id
      post_pm_count[chamber] += 1
      if phase[chamber] == PHASE_0:         # Phase 0: 새-레짐 중심 축적(바운드 N) — new_center 소스(G)
          for p in points: _phase0_center[chamber][p.group_key].update(p.value)  # 그룹별 러닝 평균 (Qual 5장도 여기 유입)
      elif phase[chamber]==PHASE_1 and post_pm_count[chamber] >= boundary[chamber]:  # ③ 정착
          phase[chamber] = AWAITING_PHASE2  # 신호 1회만 발행 (재발행 방지 — Review3; 탈출은 on_firm_established)
          _persist(chamber)
          return PHASE2_SIGNAL(chamber)     # 실제 재산정은 b

  on_firm_established(chamber):             # ⑤ provisional 탈출 전이 — c 배선이 firm 적용 시점 호출 (b 결정4)
      if phase[chamber] != AWAITING_PHASE2: return   # ★Phase 2 정착 후에만 (멱등·오상태 무시). 반려 시 미호출→holding 유지
      _provisional_chambers.discard(chamber)         # union에서 제거
      tttm.set_excluded(_provisional_chambers)       # TTTM 복귀 (남은 union 전달 — Review B, 교체 시맨틱)
      _phase0_center.pop(chamber, None)              # 새-레짐 중심 버퍼 정리
      phase[chamber] = NORMAL
      _persist(chamber)

  get_phase(chamber) -> Phase               # ④ 알람 게이트가 매 wafer 조회 (억제 판단)

  restore(state):                           # 재시작 (c): 주입 state로 전 필드 복원
      # {phase, post_pm_count, verdict, boundary, last_pm_count} 라운드트립 (일부만 복원 시 boundary KeyError·카운터 리셋)
      # phase←control_limits(provisional 활성) 파생·verdict는 provisional-활성이 loud 함의(quals=PASS/FAIL, 직접 복구 X) · post_pm_count만 별도 영속
      # PHASE_1·AWAITING_PHASE2 챔버 → _provisional_chambers 재구성 후 tttm.set_excluded(union) 재적용
      #   (둘 다 firm 전까진 provisional-active·TTTM 제외 상태 — AWAITING_PHASE2 누락 시 재시작 후 조기 fleet 복귀→오염. excluded는 tttm 인메모리라 유실)
```

**Phase 1 광폭 산식 (`_make_provisional`) — 결정 3 (★Review A·C·D 반영):**
```
new_center[gk] = _phase0_center[chamber][gk] if n≥min_n else current[gk].center   # 새-레짐 중심(G, Phase0 버퍼). 부족 → old_center fallback (Review2)
for gk in groups:
  σ_ref = sigma_ref_of(current[gk], cfg.k_sigma)     # ★헬퍼 호출 (Review C) — sigma면 .sigma / quantile이면 (ucl−lcl)/2k. q_ucl/q_lcl 인라인 금지
  half  = cfg.provisional_k · σ_ref                  # 광폭 반폭 ⚠️provisional_k 실측필수
  if current[gk].method == 'sigma':
      # ★Nelson은 sigma 그룹서 from_limit(center,sigma)로 판정(s3p=center+3·sigma) — ucl/lcl 무시(nelson_rules:37,57).
      #   따라서 광폭은 sigma 컬럼에 인코딩해야 억제됨 (Review A):
      sigma_prov = cfg.provisional_k / 3.0 · σ_ref    # 3 = Nelson N1 외곽존 고정(nelson_rules:37) → 3·sigma_prov = half
      emit(gk, center=new_center, sigma=sigma_prov,
           ucl=new_center+half, lcl=new_center−half,  # ucl/lcl은 리포트 일관용(nelson_engine:232)
           method='sigma')
  else:  # quantile — Nelson은 from_quantile(center,lcl,ucl)로 판정(s3p=ucl, nelson_rules:53) → ucl/lcl 확대가 유효
      emit(gk, center=new_center, sigma=current[gk].sigma,   # sigma는 참고통계 유지(NOT NULL)
           ucl=new_center+half, lcl=new_center−half,
           method='quantile', q_low=승계, q_high=승계)
```
