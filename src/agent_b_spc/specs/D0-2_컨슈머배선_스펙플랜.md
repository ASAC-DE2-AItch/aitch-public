## 1. 목적

Nelson(B3-1)·TTTM(B4-2) 판정 엔진은 완성됐으나 **주입식 순수 함수**라 스스로 데이터를 안 받는다(지금까진 테스트가 합성 데이터를 손으로 먹임). D0-2는 이 엔진들에 **실시간 `fdc.raw` 스트림을 연결하는 컨슈머**다.

> **어려운 건 Kafka가 아니라 집계다.** Kafka는 배달만 하고(파이프), raw 3초 샘플 → 웨이퍼 요약 Point 변환·팬아웃은 전부 **이 컨슈머 앱 코드** 몫. 핵심 난제 = **raw→Point 집계(§5) + 웨이퍼 완성 트리거(§4)**.
> D0-2 = **입력 앞문**(fdc.raw → 엔진). 위반을 Context Score로 합쳐 `fdc.alert` 발행하는 **뒷문은 B4-1**. D0-2는 위반을 **만들기만** 한다.

## 3. 트리거 · 경계

- **상류** — 시뮬레이터가 `fdc.raw`(3초 샘플 row) 발행. B는 **`consumer-group-spc`** 로 구독.
- **D0-2 책임** — `fdc.raw` → 집계 → Point → `nelson.feed`·`tttm.feed`+`chamber_rollup` → 결과 수집(2 seam). **그게 전부.**
- **이월 (범위 밖)**:
  - `fdc.alert` **발행** + `context_score` 계산 = **B4-1**(Nelson+TTTM+drift_score 합산·게이트 ≥31)
  - `fdc.correction`/`prediction`/`agent` 구독 = 각 태스크(**B5-1a**/B4-1/B6-3)
  - `spc_violations` DB 적재 = `alert_id` 의존 → **B4-1** 이후
  - **exact-once / 재전달 중복 feed · 버퍼 상한(24h OOM)** = **B7-1**(D0-2는 at-least-once까지)
- **A 공유** — Kafka 유틸·직렬화·bootstrap(D0-2 A+B 공동). B쪽 고유 = 집계+Point+팬아웃.

## 4. 처리 흐름 (메인 루프) ★

```
[startup]
  engine = make_engine()                                   # DB 엔진 (seed_control_limits 패턴)
  limits, whitelist = control_limits_loader.load(engine)   # 1회 스냅샷 (결정 5)
  nelson = NelsonEngine(limits, whitelist)
  tttm   = TTTMEngine(limits, whitelist)
  consumer.subscribe(["fdc.raw"])                          # 디스패치 뼈대 (결정 1 — 나중 토픽 추가)
  buffers: dict[chamber_id → {wafer_id, rows[], last_row_time, last_offset}] = {}

[loop]
  msg = consumer.poll(timeout=t)
  _sweep_idle(now)                                         # 타임아웃 tail 상시 점검 (결정 2)
  if msg is None: continue
  try: row = json.loads(msg.value)
  except: log.warning(역직렬화 실패 skip); continue         # 헌법 6-2 (결정 6)
  if not _valid(row): log.warning(필수필드/형식 오류 skip); continue    # (H2) 아래 _valid
  if msg.topic() == "fdc.raw": _handle_raw(row, msg.offset, now)
  # 커밋은 per-message가 아니라 flush 시 (M1 — at-least-once)

[_valid(row)]  # H2 — 집계·Point가 하드 요구하는 필드 전부 검사
  required 존재: wafer_id · chamber_id · recipe_id · step · stabilization_flag · pm_count · sensors(비어있지 않음)
  timestamp: ISO-8601 형식 (파싱 가능)
  → 하나라도 없으면 False

[_handle_raw(row, offset, now)]                            # 경계 감지 (결정 2)
  ch = row["chamber_id"];  buf = buffers.setdefault(ch, 빈버퍼)
  if buf.wafer_id and row["wafer_id"] != buf.wafer_id:     # 새 wafer_id → 직전 웨이퍼 완성
      _flush(ch)                                           #   (이 시점 buf.last_offset = 직전 웨이퍼 마지막)
  buf.wafer_id = row["wafer_id"];  buf.rows.append(row)
  buf.last_row_time = now;  buf.last_offset = offset

[_flush(ch)]                                               # 집계 → Point → 팬아웃 (결정 3·4·6)
  buf = buffers[ch];  if not buf.rows: return
  try:                                                     # P3 — 예외에도 reset 보장
      points = _aggregate_to_points(buf.rows)              # §5 브리지 (역리네이밍·파생·집계·Point화)
      spc_flags = []
      for p in points:
          try: nv = nelson.feed(p)                         # Nelson: 위반 (rule_id·sensor_id 보유)
          except Exception: log.exception("nelson feed 실패"); nv = []
          spc_flags += _to_spc_flags(nv)                   # → [{sensor, rule}] (계약, Nelson 전용 — H1)
          try: tttm.feed(p)                                # TTTM: state 축적만 (반환=텔레메트리, 위반 아님 — H1)
          except Exception: log.exception("tttm feed 실패")
      tttm_obj = tttm.chamber_rollup(ch)                   # TTTM 판정 객체 (score·top_gap_sensor·reference_suspect — H1)
      if spc_flags or tttm_obj:
          log.info("판정 %s: nelson=%s tttm=%s", buf.wafer_id, spc_flags, tttm_obj)
          _collect(buf.wafer_id, spc_flags, tttm_obj)      # seam → B4-1 (Nelson·TTTM 별개 shape)
      consumer.commit(upto=buf.last_offset)                # M1 — flush된 웨이퍼까지만 커밋 (at-least-once)
  except Exception: log.exception("flush 실패 — 루프 생존")
  finally:
      buf.reset()                                          # 예외 나도 이전 rows 반드시 비움 (오염 방지 P3)

[_sweep_idle(now)]                                         # tail (결정 2)
  for ch in list(buffers.keys()):                          # P1 — 키 리스트 복사 순회
      buf = buffers[ch]
      if buf.rows and now - buf.last_row_time > cfg.wafer_idle_flush_sec:
          _flush(ch)

[shutdown]  SIGINT/SIGTERM →                               # 헌법 6-2
  for ch in list(buffers.keys()): _flush(ch)               # 남은 버퍼 전부 flush (+커밋)
  consumer.close()
```

**flush 두 경로** — 경계 감지(정상)·타임아웃(idle/tail) 둘 다 `_flush` 하나로 수렴. `_flush`가 웨이퍼 하나의 모든 그룹 Point를 두 엔진에 먹임(팬아웃).
**엔진 비대칭 (H1)** — **Nelson `feed` 반환 = 위반**(spc_flags 수집) / **TTTM `feed` 반환 = 텔레메트리**(state 축적만, 수집 안 함) → **판정은 `chamber_rollup(ch)`** 로 별도. 계약상 두 산출물이 별개.
**커밋 (M1)** — flush될 때 그 웨이퍼 마지막 offset까지만 커밋 → 크래시 시 미flush 웨이퍼 재전달(at-least-once). 재전달 중복 feed는 B7-1.
**멀티챔버** — `buffers`가 chamber별 분리로 인터리브 자연 처리.

## 5. 집계 브리지 + Point 매핑 — `_aggregate_to_points(rows)` ★

**핵심**: `build_wafer_summaries`는 배치 산식이라 **C코드 컬럼**을 하드 요구한다. 라이브 `fdc.raw`는 필드명이 다르고 파생 컬럼이 없으므로, **브리지가 df를 배치와 동일 형태로 재구성**해야 한다. 순서:

**① 소형 df 재구성 (역리네이밍 + C10 주입 — C2)**
버퍼 rows → DataFrame. fdc.raw top-level → `build_wafer_summaries` 입력 C컬럼으로 **역리네이밍**:

| fdc.raw | → C컬럼 | 용도 |
|---|---|---|
| `chamber_id` | `C24` | groupby 축 |
| `recipe_id` | `C6` | groupby 축 |
| `step` | `C7` | groupby 축 |
| `stabilization_flag` | `C42` | window(과도/정착) |
| `wafer_id` | `C64` | groupby 축 |
| `timestamp` | **`C10` 주입** | 정렬용(`agg("C10","min")=t0`) — **없으면 KeyError** |
| `sensors:{C11,...}` | 각 센서 컬럼 | value 원천 |

**② `add_derived_features(df)` 선행 (C1 — 필수)**
`build_wafer_summaries`는 `sensors = SENSORS_SETTLED + DERIVED_SETTLED(=D_VDC_RES) + SENSORS_TRANSIENT_ONLY`를 순회하며 **`D_VDC_RES` 컬럼을 무조건 참조**한다(`initial_limits.py`). `add_derived_features`(`D_VDC_RES = C11 − C12`)를 **먼저** 적용하지 않으면 매 flush `KeyError` → 0 point(무음 전면 실패). *(main도 `add_derived_features → build_wafer_summaries` 순서.)*

**③ `build_wafer_summaries(df)` → 요약 df**
step×window×sensor **평균** 산출(배치와 동일). window=C42, 과도전용 센서 필터 포함.

**④ 요약 df 각 행 → Point**

| Point 필드 | 소스 | 비고 |
|---|---|---|
| `group_key` | `normalize_group_key(C24, C6, int(C7), sensor_window, sensor_id)` | **step=int 강제** · window=settled/transient |
| `value` | 요약 mean | 배치=라이브 일치 (결정 3) |
| `limit_version` | **`limits.get(gk)`** → 없으면 **Point 생략** (M3) | 비화이트리스트 그룹 `limits[gk]` KeyError 방지(엔진 skip 전에 브리지가 먼저 죽는 것 차단) |
| `pm_count` | **버퍼에서 별도 추출**(웨이퍼 상수 — 예: rows[-1]["pm_count"]) (M2) | `build_wafer_summaries`가 안 실어나름 |
| `timestamp` | 웨이퍼 **t0**(C10 min) — **`Z`→`+00:00` 정규화**(str 유지) (C3) | 엔진 `fromisoformat`가 `Z`를 <3.11서 못 파싱 → `str.replace("Z","+00:00")`. **datetime 변환 아님**(str 유지, 엔진 계약 OK) |
| `wafer_id` | `C64` 전체(`_CH_` 포함) | 인스턴스 유일키 |

> **왜 normalize 필수** — 라이브 gk와 로더 whitelist gk의 타입(특히 step int/str)이 어긋나면 전 그룹 조용히 skip = 조용한 참사. `normalize_group_key`(step=int)로 양쪽 통일. 엔진의 "감시 대상 아님 skip 로그"가 오설정 감지망.

## 6. 엔진 초기화 · 리로드 seam

- **초기화** — startup 시 `control_limits_loader.load(engine)` 1회 → `(limits, whitelist)` → 두 엔진 생성 (engine=`make_engine()`). **whitelist는 startup-only**(운영 중 불변).
- **리로드 seam** — 관리선(limits)은 B4-3 재산정·B5-1a 승인으로 **운영 중 바뀜**. D0-2는 **`reload_limits()`/`update_limit(gk)` seam만 제공**, 실제 **`fdc.correction` 구독 → 리로드 트리거는 B5-1a 이월**. `Point.limit_version` 변경 → 엔진이 해당 그룹 상태 리베이스로 흡수.

## 8. 범위 밖 · 이월

- **`fdc.alert` 발행 + `context_score` 계산** = **B4-1** (Nelson spc_flags + TTTM tttm_obj + drift_score 합산·게이트·severity). D0-2는 2 seam까지.
- **`fdc.correction` 구독 → 리로드 트리거** = **B5-1a**.
- **`fdc.prediction`/`fdc.agent` 구독** = B4-1·B6-3.
- **`spc_violations` DB 적재** = `alert_id` 의존 → B4-1 이후.
- **오프셋 정밀 관리 · 재전달 중복 feed(exactly-once) · 버퍼 상한(24h OOM)** = **B7-1**. *(D0-2 M1은 "flush 후 커밋"으로 in-flight 유실 방지 의도까지. ⚠️ `fdc.raw`는 **wafer_id 키 파티셔닝**이라 정확한 at-least-once는 **per-partition min un-flushed offset** 관리가 필요 — `commit(upto=buf.last_offset)`는 단순화 표기. 이 offset 정밀 관리 + 재전달 중복 feed 멱등은 B7-1.)*
- **`wafer_idle_flush_sec`** — params.yaml `spc:` 등재·로드는 B(D0-2-2). **값 확정 = dry-run 측정 후** · **PM 합의안 doc 등재 = 후속 요청**(non-blocking, 헌법 4-3).

## 10. 테스트 계획

**순수 (DB·Kafka 없이)**
- **집계 일치** — 같은 웨이퍼 raw를 브리지(`_aggregate_to_points`) vs 배치(`add_derived_features`+`build_wafer_summaries`) → **value 동일** (C1·C2 포함 — 파생·리네이밍 후에도 산식 괴리 0)
- **파생 필수 (C1)** — `add_derived_features` 생략 시 KeyError 재현 → 브리지가 선행함을 assert
- **필드 재구성 (C2)** — 역리네이밍(chamber_id→C24 등)+C10 주입 후 groupby 정상
- **timestamp Z 정규화 (C3)** — `"...000Z"` → `"...000+00:00"` str · `datetime.fromisoformat` 파싱 성공 · **str 유지**(datetime 아님)
- **TTTM 비대칭 (H1)** — `tttm.feed` 반환은 spc_flags에 안 섞임 · `chamber_rollup(ch)`가 tttm_obj 별도 산출
- **`_valid` 확장 (H2)** — recipe_id·stabilization_flag·pm_count·sensors 결측 → skip
- **limits.get 가드 (M3)** — 비화이트리스트 그룹 → Point 생략(KeyError 없음)
- **pm_count 추출 (M2)** — 버퍼에서 pm_count가 Point에 실림(build_wafer_summaries가 drop해도)
- **완성 트리거** — 경계 감지 · 타임아웃 tail · shutdown flush · 부분 웨이퍼(있는 그룹만) · 멀티챔버 인터리브
- **flush 오염 방지 (P3)** — 브리지 예외 → `finally` reset → 다음 웨이퍼 안 섞임
- **엔진 격리** — 한 엔진 예외 → 다른 엔진·루프 생존 · **역직렬화 방어**(깨진 JSON → skip)
- **커밋 (M1)** — flush 후 buf.last_offset까지만 커밋(미flush 웨이퍼 재전달 창)

**통합 (skipif — mock 스트림, Python ≥3.11)**
- 시뮬레이터 dry-run `fdc.raw`(또는 mock jsonl) → consume → **Nelson spc_flags + TTTM tttm_obj 관통 확인** (라이브 Kafka는 docker compose 대기). ⚠️ 빠른 replay면 idle tail 미발동 → 마지막 웨이퍼는 shutdown flush 의존(주입 clock 권장, L2).
