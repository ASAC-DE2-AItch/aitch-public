## 2\. 확정 결정 (구현 앵커)

**판정 로직**

1. **판정 방식** \= σ 기반 수렴. A10 dead band(`recalc_engine.py:155`)의 **`k_se` 계수를 재사용**(신규 임계 키 없음). SE는 2\-표본으로 확장(§2\-5).
2. **판정 신호** \= 센서 그룹 center 값(예측 C65 아님 — 제안서 §4 기각). 그룹 \= `group_key`(챔버×센서 C코드×step).
3. **판정 대상 그룹** \= **whitelist(준\-꺼짐 배제).** ⚠️ **ProvisionalMode엔 whitelist가 없음(리뷰3 \#1)** — `provisional_mode.py`에 인자·속성 부재(grep 0). whitelist는 **SpcConsumer 소유**(`spc_consumer.py:190·233`). → **`ProvisionalMode.__init__`에 whitelist 인자 신설 \+ `_build_provisional`(`spc_consumer.py:753`)에서 `whitelist=whitelist` 주입**(§4\-1). ⚠️ 선결(리뷰2 \#2): whitelist는 `control_limits_loader`가 **active control\_limits 그룹**으로 만든 것(`:61`)이라, 준\-꺼짐(`EXCLUDE?`)이 **시딩(B3\-2)에서 빠졌는지 확인** — 안 빠졌으면 `monitoring_whitelist` 분류를 명시 적용.
4. **창 \= 비중첩 블록.** 길이 W 블록을 겹치지 않게 이어 붙이고, **블록이 완성될 때마다(매 W장)** 직전 블록과 비교. 슬라이딩 아님(PM 확인 항목).
5. **정착 조건**\: 그룹 g에 대해 `Δ_g = |mean(최근 블록) − mean(직전 블록)| / σ_ref(g)`, **`settle_band = deadband_k_se · √(1/n_recent + 1/n_prev)`** (n\=블록 유효표본. **A10 `k_se` 계수를 2\-표본 SE로 확장** — 두 블록 다 꽉 차면 `√(2/W)`. res\_σ 미적용, 리뷰2 \#8). `Δ_g < settle_band`가 **M회 연속**이면 그룹 정착. **실패 시 연속 카운터 0으로 리셋.**
6. **챔버 정착 \= 모든 대상 그룹 동시 충족.** 한 블록 경계에서 대상 그룹 **전부**가 **이번 경계 평가 가능(유예 아님) \+ 연속 M 이상**일 때 정착(latch 아님).
7. **하한** `settle_min_wafers = 600`. 코드 유효 하한 \= `max(settle_min_wafers, (M+1)×W)`. (W\=200·M\=2 → 600.)
8. **상한** `seasoning_exclude_wafers_loud = 1000`(기존 값·의미만 "고정 경계 → 상한"). 미수렴 시 현행과 바이트 동일.
9. **미수렴 플래그**\: 상한 1,000 도달 시 미달이면 `Phase2Signal.converged = False`. 승인자(R9)·Supervisor 경고용.

**σ\_ref 소스 (리뷰2 \#3 · 리뷰3 \#2 — 재시작 오염 방어)**

`σ_ref(g)`는 **firm 관리선 기준**(광폭 provisional 아님). `self.limits` 직접 사용 금지.

- **이유**\: `self.limits`는 `__init__` 1회 바인딩이고, **Phase 1 중 재시작**하면 `control_limits_loader.load`가 **active\=광폭 provisional**을 반환 → `sigma_ref_of`가 광폭 σ(\~`provisional_k/3`배) → 밴드가 넓어져 **가짜 converged\=True** → 오염 baseline에 firm 수립(막으려던 사고).
- **정상 진입**\: `_enter_phase_1`에서 광폭 write **전에** firm σ\_ref를 그룹별 스냅샷(`self._settle_sigma_ref`).

**블록 평가 가능 요건 · 유예 (리뷰1 ①④ · 리뷰2 \#4\#9)**

한 그룹의 한 블록은 아래 둘 다 만족해야 **평가 가능**\:

- **(i) 최소 유효비율** — `n ≥ W × settle_block_min_fill`(출발 0.5). TTTM `tttm_window_min_fill`(\=10/20\=50%) 승계.
- **(ii) σ\_ref 퇴화 가드** — `σ_ref(g) ≤ EPS`면 유예. **A10 `recalc_engine.py:132` `if sigma_ref <= EPS: reason="degenerate"`(skip) 패턴**(리뷰2 \#6 — :150은 reset\_ref 가드로 무관).

**유예 처리**\:

- **동시충족 배제(\#4)** — 유예 그룹은 그 경계에서 "충족"으로 안 침. `_is_settled`는 **"이번 경계 평가 가능(유예 아님) \+ streak ≥ M"** 을 함께 요구(streak\=2 후 센서 죽어 유예된 그룹의 조기 정착 방지).
- **블록 롤·리셋(\#9)** — 유예 블록은 **폐기**\: `prev` 롤 안 함·`[sum,n]` 리셋·`streak` 유지.

> ⚠️ **부작용(수용)**\: 어떤 그룹이 계속 평가 불가면 동시충족 불가 → **1000 폴백(converged\=False)**. 보수적(영구 죽은 그룹은 준\-꺼짐 배제, 플래키는 폴백 흡수).

## 3\. 판정 알고리즘 (검사 캐던스)

**검사 단위 \= W장마다 1회** (블록 완성 시점). 매 wafer 아님.

W\=200·M\=2 예시: 평가 400·600·800·1000, **가장 이른 정착 600**(M\=2 연속), 지점 600·800·1000(200장 해상도 \= 비중첩 결과). `Δ_g ≥ band`면 그 그룹 streak\=0. 동시충족 \= `post_pm ≥ max(settle_min,(M+1)W)` 그리고 대상 그룹 전원 "이번 경계 평가 가능 \+ streak ≥ M".

**블록 완성 시 그룹별 처리**

1. 대상 그룹(**whitelist**)만 현재 블록에 `value` 누적 → `[sum, n]`.
2. **평가 가능?** `n ≥ W × settle_block_min_fill` **그리고** `σ_ref(g) > EPS`(firm 스냅샷) — 아니면 **유예**(블록 폐기·`[sum,n]` 리셋·`prev` 롤 안 함·`streak` 유지·eval\_ok\=False).
3. 평가 가능이면: **`prev` 없으면**(첫 블록·유예 직후) 비교 skip·롤만(무크래시). 있으면 `Δ_g = |mean − prev|/σ_ref`, `band = k_se·√(1/n + 1/n_prev)`, `Δ < band`면 `streak++` 아니면 `streak = 0`. eval\_ok\=True.
4. 현재 블록 mean을 `prev`로 롤(유효표본 `n_prev` 동반)·`[sum, n]` 리셋.

**상태 (provisional\_mode, 미영속 링 버퍼)**

- `self._settle_block[chamber][gk] = [sum, n]` · `self._settle_prev[chamber][gk] = (mean, n_prev)` · `self._settle_streak[chamber][gk] = int` · `self._settle_eval_ok[chamber][gk] = bool`(이번 경계 평가 가능, 동시충족 게이트).
- `self._settle_sigma_ref[chamber][gk] = float` — **firm σ\_ref**(정상\=`_enter_phase_1` 스냅샷 / 재시작\=`restore()` DB 재파생, 리뷰3\#2. 별도 영속 없음).
- 링 버퍼 미영속(재충전 \~2W 지연, 결정2 ⓓ).
