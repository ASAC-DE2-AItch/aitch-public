# 실력치 재산정 엔진 (B4-3) Implementation Plan

> 설계 근거: `src/agent_b_spc/specs/B4-3_실력치재산정_설계.md` (v2) · 결정 정리 `specs/B4-3_실력치재산정_결정.md`.
> **For agentic workers:** Task 단위 TDD (Step 1 실패테스트 → Step 2 구현 → Step 3 검증). 코어는 DB·Kafka 불요(값·기준점 주입) — 라이브는 B5-1. 리뷰 3중(자체 12 + 서브에이전트 + 교차) 반영분을 각 Task 불변식에 못박음.
> ⚠️ git: push는 origin(B파트)만. upstream 금지. git 조작은 오너(B) 직접.

**Goal:** 정기 리캘리 시점에 `(group_key, 최근 N장 값, 현행 관리선, 리셋 기준점, 분해능)` → 새 관리선 재산정 + **변화없음/자동적용/승인대기** 판정(`recalc_engine.recompute_group`). 자동 케이스만 control_limits(새 버전) + limit_corrections(이력) 반영(`recalc_writer`). 누적은 telescoping(`|new−reset|/reset σ`), 리셋 기준점은 2-소스 병합(`correction_history`).

**Architecture:** `recompute_group`(순수) → RecalcProposal → **자동이면 `apply_auto` / 승인대기면 `record_proposed`**(둘 다 DB, commit=호출자). 산식은 `initial_limits.compute_group_limits`(추출) 공유. 자(尺): 1회=활성 σ, 누적=시작 σ. reference·whitelist는 `control_limits_loader`(B3-2) 재사용.

**Tech Stack:** Python, numpy(산식)·`statistics`(NormalDist Φ⁻¹ 가드), SQLAlchemy(writer/history), pytest. Point/config 패턴은 기존 B 모듈 관례.

## Global Constraints (헌법 + 리뷰 불변식)

- **헌법 1-1**(HITL): 정기+상한이내 자동+이력(예외 ⓐⓑ). **무이상(ⓒ)은 상류(B5-1) 게이팅** — 코어는 무이상 전제만 문서화(§3-6). 초과·이상은 승인(코어는 PROPOSED 발행까지).
- **헌법 1-3**: 과거 정상 wafer 센서값만 — C65·미래정보 미사용.
- **헌법 3-2**: control_limits **무변경**. limit_corrections `delta_sigma`는 upstream 반영 수용(되돌리지 않음).
- **헌법 4-1**: 새 limit_version(**그룹별**) + 기존 is_active=false 보존.
- **헌법 6-1**: 매직넘버 금지 — `2·k_sigma`(6 하드코딩 금지), EPS 상수, config 키.
- **헌법 6-4**: snake_case · C코드 · `correction_id = LIM-<YYYYMMDD>-<CHAMBER>-<SEQ>`.
- **리뷰 불변식(구현 중 준수)**:
  - **H-A**: `sigma_ref`·`reset σ`·소표본 가드는 **모든 나눗셈 前**(계산 뒤 가드 금지 — ZeroDivision).
  - **H-B**: writer는 `correction_id`(NOT NULL UNIQUE) 필수 채움 — 경합 안전 채번.
  - **쓰기 순서**: control_limits는 **UPDATE(is_active=false) 먼저 → INSERT** (active 유일 인덱스 immediate check).
  - **M-A**: 리셋 기준점 = control_limits `initial`(v1) 기저 + limit_corrections `{qual,incident,APPROVED_APPLIED}` 최신 덮어쓰기. (initial은 limit_corrections에 없음.)
  - **H2·H3**: 누적 = `|new−reset|/reset σ` (signed 순이동·시작 σ). delta_sigma 합산 금지.
  - **M-C**: `group_key`가 코어→proposal→writer로 흐름.
  - status 영문(`AUTO_APPLIED`/`PROPOSED`/…). commit=호출자.
  - **M7**: `reset_ref`가 `None`(리셋 기준점 부재)이면 코어는 `needs_approval` 보수 처리 — `None.sigma_ref` 금지.
  - **L5/L7 상수화**: status·trigger 리터럴은 모듈 상수(`seed_control_limits.TRIGGER_INITIAL` 선례), `EPS`는 **공용 위치 1개**(tttm에 이미 1e-9 존재 — 재정의 금지).
  - **병렬(L4)**: 실제 의존은 `0 → 1 → 2 → 4 → 5`. **Task 3은 `sigma_ref_of`(Task 2 초반) 확정 후 Task 2와 병렬 가능**.
