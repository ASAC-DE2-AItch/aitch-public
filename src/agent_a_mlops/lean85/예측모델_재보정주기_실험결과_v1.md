### 기전 요약 (수치에서 기계적으로 도출)

- 재보정 이득의 구간별 순위(워밍업 제외): onset_minor +10.69% > onset_major +5.17% > steady +2.90%
- ARM-STATIC 은 평시 342.369 인데 major PM 온셋에서 194.77 로 **좋아진다** — M0 가 실측 구간(마지막 major PM 이후 = 고레짐)만 보고 학습해 그 레짐에서만 맞는다. 즉 STATIC 의 발산은 점진적 열화가 아니라 **레짐 고착**이다 — 사전 등록 R4 의 전제 이탈이다 (§7 한계·부록 A-6 v1.2).
- 위 둘을 합치면 이 데이터에서 재보정이 사는 지점은 '시간 경과 열화'가 아니라 **'레짐 전환 적응'** 이다. 사전 등록 R3(평시 7일 + 요란 PM 직후 즉시 — 부록 A-4)이 그린 구조와 같은 방향이며, R1 이 먼저 발동한 것은 워밍업 포함 pooled 가 임계를 크게 넘겼기 때문이다.

## 7. 한계 (해석 시 필수)

> **y 커플링 부재**: 이벤트 16건·aging 은 **센서 층만** 주입(y 무반응 — 생성설계 명시 가정). 측정되는 재학습 이득은 주로 "X 분포 이동 적응 + PM 주변 y 패턴"이며, 실제 팹의 y 드리프트 적응분은 **과소 반영**된다.

따라서 본 결과는 **합성 가정 하 하한 추정**이다. 실제 팹에서 재보정 이득은 여기서 측정된 값보다 클 가능성이 높고, 그 방향은 D1 에 유리하다 — 이번처럼 R1 이 나왔더라도 그 효과 크기는 과소 추정일 수 있고, 반대로 R2(완화)가 나왔다면 "주기를 늘려도 안전하다"의 근거로 쓰기엔 이 실험 하나로는 부족했을 것이다.

| 위협 | 본 실험에서의 처리 |
|---|---|
| 이음새 단차 | 평가 첫 7일 별도 표기 + 제외 민감도 실행 — §3 참조. **주 판정 효과 크기의 대부분이 여기서 나온다** |
| 매핑 근사 | **해소** — C40 실측 시각 사용 (부록 A-6 v1.1 정정, 하네스 README ①) |
| 판정 라벨 즉시 인지 | 요란/조용 판정 지연을 무시하는 단순화 가정 |
| 합성 major 2회 | 온셋 표본 = 레짐 2개 — 통계력 낮음, 효과 크기 중심 서술. 부속 런에서 온셋 개선폭이 3.05~5.17% 로 흔들려 R3 임계(5%✱)를 걸친다 — **하이브리드 안의 근거로는 쓸 수 없다** |
| M3 요일 완전 교락 *(실행 중 발견)* | model age 슬롯이 요일에 1:1 고정 — 원 곡선의 기울기는 열화 + 요일 효과의 합이다. **M3-adj 병기**로 대응했고 age 0 항등 검사로 분해를 검증했다 (부록 A-6 v1.2) |
| R4 전제 이탈 *(실행 중 발견)* | STATIC 이 발산(=334.237)해 R4 는 미발동했으나, 그 정체는 점진적 열화가 아니라 **레짐 고착**이다 — 재보정 이득을 '시간 경과 열화 적응'이 아니라 '레짐 전환 적응'으로 서술한다 (부록 A-6 v1.2) |
| 게이트 시뮬 사후성 | 챔피언·챌린저 모두 out-of-sample 인 동일 셋에서 비교하므로 낙관 편향은 없다. 다만 **결정 시점에는 가질 수 없는 라벨을 쓰는 사후 소급 판정**이라 운영 게이트의 실제 거동과는 다르다 (§5 부속) |

## 8. 부록 A — 사전 등록 설계 요약 (설계서 대체)

설계서(`예측모델_재보정주기_실험설계_v1.md` v1.2)는 A 작업물이라 리포에 포함하지 않는다(CLAUDE.local.md). 리뷰에 필요한 사전 등록 내용을 아래에 옮겨 싣는다 — **판정 규칙과 임계는 결과를 보기 전에 확정한 것**이며, 코드에서는 `CONFIG.py` 한 곳에만 존재해 변경 이력이 git 에 남는다.

### A-1. 실험 질문 (사전 등록)

| 번호 | 질문 |
|---|---|
| Q1 | 평가구간 전체 pooled RMSE 에서 D1 이 D7 대비 얼마나 개선되는가 (유의성 포함) |
| Q2 | 개선이 있다면 **어디서** 오는가 — 평시인가, PM 직후(레짐 온셋) 구간인가 |
| Q3 | 모델 열화 곡선상 열화가 시작되는 시점은 며칠인가 |
| Q4 | D1 의 부작용(예측 churn — 잦은 교체로 인한 일관성 저하)은 어느 정도인가 |

### A-2. 실험군과 공통 통제

| 군 | 재보정 규칙 | 역할 |
|---|---|---|
| ARM-D1 | 매일 00:00, 직전일까지 데이터로 재학습 | 현행 정본 (일간) |
| ARM-D7 | 7일마다 재학습 (평가 시작일 기준 7일 그리드) | 비교군 (B2′ 프로토콜) |
| ARM-STATIC | 초기 모델 고정, 재학습 없음 | 대조군 — 재보정 효과 자체의 분리 |

**공통 통제 (3군 동일)**: 초기 모델 M0 1개 공유 · 피처 lean-85 동결셋 · 하이퍼파라미터 동결(246 rounds) · seed 42 · 학습창 min(가용 이력, 365일) · wafer→날짜 매핑 공유. **주기 하나만 조작 변인이다.**

**게이트 제외**: 운영 승격 기준(3.0%)은 주 분석에서 제외(무조건 교체)했다 — 게이트를 켜면 '주기 효과'와 '게이트 효과'가 섞여 D1·D7 격차가 통과율에 희석된다. 게이트 시나리오는 §5 부속 분석으로 분리했다.

### A-3. 백테스트 프로토콜

```
초기 학습:  train(wf_day <= 2019-02-08)        → M0  (3군 공통)
평가 루프:  for d in 2019-02-09 .. 2019-11-30:
    ARM-D1:     M_d = retrain(wf_day <= d-1)        # 매일
    ARM-D7:     if (d - 시작일) % 7 == 0: M = retrain(wf_day <= d-1)
    ARM-STATIC: M = M0
    예측:       d일 wafer 전체 → (군, d, wafer, y, ŷ) 기록
```
d일 예측에 쓰는 모델은 d-1일까지의 데이터만 학습한다(미래 차단). `pm_log` 도 재학습 시점 기준 절단본과 등가임을 실증한다(§1 누수 체크리스트 check 4).

### A-4. 판정 규칙 R1~R4 (사전 등록 — 결과 확인 전 확정)

| 규칙 | 조건 | 판정 |
|---|---|---|
| **R4** | ARM-STATIC 이 D7 과 유의차 없음 | **주기 판정 보류** — 합성 데이터가 재학습 필요성을 재현하지 못했다는 신호로 읽고 데이터 타당성 재검토로 회귀 |
| **R1** | D1 이 D7 대비 pooled RMSE 상대 **≥2.0%** 개선 + 유의(α=0.05) | **일간 유지 확정** — 실증 종결, 멘토 보고 |
| **R3** | R2 이면서 온셋 구간에서만 D1 우위 **≥5.0%✱** | **하이브리드 제안** — 평시 7일 + 요란 PM 직후 즉시 재학습 |
| **R2** | 개선 <2.0% 또는 비유의 | **7일 완화안 작성** — 멘토 확정 사항 이탈이므로 근거 패키지 + 사후 공유 절차 |

**검사 순서는 R4 → R1 → R3 → R2 다.** R4 를 맨 앞에 두는 것은 안전장치라서다 — 데이터가 재학습 필요성을 재현하지 못했다면 나머지 판정이 전부 무의미해진다. 실측 68일에서 무재학습은 pooled 254.9 로 발산함이 확인돼 있으므로(lean-85 REPORT), STATIC 이 멀쩡하다면 그것은 '무재학습이 좋다'가 아니라 '합성 구간이 드리프트를 재현하지 못했다'는 신호로 읽는다.

**R1 임계는 2026-08-04 멘토 보고에서 2.0% 로 확정됐다(✱ 해제). ✱ 가 남은 R3 임계는 R3 미발동으로 종결돼 사전 등록 제안값 그대로 보존한다.** 코드상 위치는 `CONFIG.R1_MIN_REL_GAIN_PCT` / `CONFIG.R3_ONSET_MIN_REL_GAIN_PCT` 한 곳뿐이라, 값이 바뀌면 git 이력에 남는다. 임계 변경 시 판정이 어떻게 달라지는지는 §6 임계 민감도 표 참조.

### A-5. 구간·지표 정의

| 항목 | 정의 |
|---|---|
| onset_major | major PM 후 14일 |
| onset_minor | minor PM 후 3일 |
| steady | 위 둘에 속하지 않는 평시 |
