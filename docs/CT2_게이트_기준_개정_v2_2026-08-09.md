## 1. B1 (홀드아웃 오경보율) — 3밴드 판정

### 1-1. 실측이 말하는 것

e4 홀드아웃 23/600 = 3.83%. Wilson 단측 95% CI **[2.74%, 5.34%]**.

- 원 목표 2% 대비: 하한이 2%를 넘는다 → **참 오경보율이 2% 초과임이 통계적으로 확정** (H₀: p≤2% 기각, z=3.06). 6라운드가 3.2~3.8%에 안착한 것과 정합 — e5/e6 홀짝 반전(3.17↔6.67%)은 홀드아웃 **구성** 분산이고, **중심 ~3.5%가 2% 위에 있다는 사실**은 분산으로 설명되지 않는다.
- 결론: **v1의 0.04는 "측정 오차 반영"이 아니라 "오경보 예산 상향"이다.** 이 문서는 그것을 사후 정당화하지 않고, 예산 결정으로 명시화한다.

### 1-2. 검토한 3안

| 안 | 규칙 | 결과 | 판정 |
|---|---|---|---|
| A. CI-only vs 원 목표 2% | CI 하한 > 2% 만 FAIL | **6후보 전원 FAIL** (e4 하한 2.74%) — 서빙이 ae_v1로 회귀 | 기각 |
| B. CI-only vs 예산 4% | CI 하한 > 4% 만 FAIL | 관측 ~5.1%까지 PASS — r3(4.33%, v1 FAIL)도 통과. **점추정 판정보다 완화** | 기각 (완화는 승인 사항 + 근거 없음) |
| **C. 점추정 + 3밴드 표기 (채택)** | 아래 | v1과 판정 동일 + 불확실성이 브리프에 노출 | **채택** |

### 1-3. 채택 규칙 (v1 대비 판정 무변경 — 완화 아님)

모집단 정의를 먼저 명시한다: **B1이 재는 것은 "배회 포함 실운영 정상"의 오경보율**이다 (홀드아웃 = 시간순 후미 정상 표본 — C17 장기 drift 등 배회 포함). "순수 조용한 정상"이 아니다.

```
lo, hi = Wilson 단측 95% CI (k/n)
FAIL-확정 : lo > budget          (예산 초과가 통계적으로 확정)
PASS-확정 : hi ≤ budget          (예산 내가 통계적으로 확정)
경계      : 구간이 budget 걸침 → 점추정(k/n ≤ budget)으로 판정하되
            리포트·승인 브리프에 "경계" 라벨 필수
budget = ct2_gate_l5_budget (= 현행 l5_max 0.04 승계 — PM 결정 항목 §5 · 가드 §1-4)
```

6후보 대입 (n=600, r1만 111):

| 후보 | k/n | CI | v1 (점≤4%) | **v2 3밴드** |
|---|---|---|---|---|
| r1 | 49/111 = 44.14% | [36.6, 51.9] | FAIL | FAIL-확정 |
| r2 | 21/600 = 3.50% | [2.46, 4.96] | PASS | **PASS-경계** |
| r3 | 26/600 = 4.33% | [3.16, 5.92] | FAIL | FAIL-경계 |
| e4 | 23/600 = 3.83% | [2.74, 5.34] | PASS | **PASS-경계** |
| e5 | 40/600 = 6.67% | [5.18, 8.54] | FAIL | **FAIL-확정** |
| e6 | 19/600 = 3.17% | [2.18, 4.57] | PASS | PASS-경계 |

판정 결과는 v1과 **전 건 동일**하다 — v2가 추가하는 것은 ⓐ e5처럼 확실히 나쁜 것과 r3처럼 경계인 것의 **구분**, ⓑ PASS-경계가 승인 브리프에 그대로 노출되는 것, ⓒ 표본이 커지면 경계 밴드가 저절로 좁아지는 성질이다.

### 1-4. 가드·회귀 조항 — v1 원문 승계 (PM 코멘트 ①, 2026-08-09)

v1 개정(`CT2_게이트_기준_개정_v1_2026-08-06.md` §가드·회귀 조항)의 가드를 **원문 그대로 승계**한다 (1-1 예외 2 선례 — "가드 걸고 완화, 위반 시 회귀"):

> **"시뮬 Scorecard 또는 운영에서 미탐 1건 검출 시 즉시 구기준 복귀 + 원인 규명 전 재완화 금지."**

v2에서의 적용 대상: `probe_min_detect` 측은 §3의 **0.90 복원으로 가드 대상에서 해소**되고, 이 조항은 **오경보 예산 4%(`ct2_gate_l5_budget`)에 걸린 채 존치**한다 — 미탐 1건 시 복귀 목표는 **원 목표 0.02**다. 즉 §5 #1의 예산 승인은 이 가드를 전제로 하며, 4%는 무조건 예산이 아니라 **"가드 걸린 완화"**로 남는다.

### 1-5. 표본 설계 연동 (WP-4) *(구 1-4 — 2026-08-09 재번호)*

p≈3.5% 가정 CI 반폭: n=600 → ±1.25%p, **n=800 → ±1.08%p**, n=1200 → ±0.88%p. 예산 4%와 원 목표 2%를 구분하려면(반폭 <1%p) **홀드아웃 ≥ ~800장**이 필요하다. WP-4 스윕의 `min_train_wafers × val_frac × gate_holdout_frac` 조합에 이 하한을 반영한다.

## 2. B5 (챔버별 L5) — 판정 가능성 문제와 처방

실측: 4챔버 **전부** CI 상한이 임계 5%를 초과한다 (n=150 → 오경보 1건 = 0.67%p, CI 반폭 ±3%p).

| 챔버 | k/n | CI 상한 |
|---|---|---|
| CH1 | 6/150 = 4.00% | 7.55% |
| CH2 | 6/150 = 4.00% | 7.55% |
| CH3 | 7/150 = 4.67% | 8.39% |
| CH4 | 4/150 = 2.67% | 5.81% |

즉 현 표본에서 B5는 "5% 이내임을 확인"하는 게 아니라 "**5% 초과가 확정은 아님**"까지만 판정할 수 있다. 처방: B1과 같은 3밴드 준용(경계 = 점추정 판정 + 라벨). `chamber_min_wafers` 20은 밴드 표기 전제로만 유지 — 20장에서 5%는 1건이 곧 5%라 사실상 이진 판정임을 리포트에 명시한다. 챔버당 홀드아웃 150 → 300 상향은 WP-4에서 B1 하한(800 총계)과 함께 결정.

## 3. C1 (프로브 검출률) — w_c 가중 채점 + 원값 0.90 복원

### 3-1. 실측

4σ 채널별 검출률 × 부록 A 손실가중(w_c):

| 채널 | rate | w_c | | 채널 | rate | w_c |
|---|---|---|---|---|---|---|
| **C52** | 0.4608 | 0.7 | | C16 | 0.9883 | 1.0 |
| **C17** | 0.6342 | 1.0 | | C15 | 0.9958 | 1.0 |
| C57 | 0.9575 | 0.3 | | C9 | 0.9983 | 1.0 |
| C58 | 0.9708 | 0.5 | | C11 | 0.9992 | 1.0 |
| C63 | 0.9792 | 0.7 | | C31 | 0.9992 | 1.0 |

산술평균 **0.8983** (현행 판정값) → 가중평균 **0.9019**.

### 3-2. 채택 규칙

```
C1 판정값 = Σ w_c·rate_c / Σ w_c   (w_c = constants.feat_weight — 부록 A 단일소스)
임계     = 0.90 (원값 복원)         → probe_min_detect 0.875 완화 철회
산술평균은 리포트에 병기 (비교·감사용)
```

근거: 채점이 이미 채널 중요도를 반영하는 손실가중(부록 A, P4 학습곡선 확정)과 정합해진다. 저중요 채널(C57 w=0.3)의 우연 성적과 고중요 채널이 같은 무게로 평균되는 왜곡 제거. **임계 복원은 강화이므로 PM 승인 불요** — 단 v1 완화의 철회이므로 개정 이력에 명시.

### 3-3. 남는 숙제 (v2 범위 밖 — 기록)

C17(w=1.0)이 63.4%로 진짜 약채널이다. C17은 배회(장기 drift) 채널이라 VAL σ가 부풀어 ±4σ 교란이 상대적으로 커야 함에도 검출이 낮다 — 조건화 정밀도 P에서 C17 잔차 방향이 눌리는지 조사 필요. σ그리드 ROC(1σ 22.3% → 6σ 96.0% 단조)는 현 판정점 4σ가 급경사 구간을 벗어난 안정 지점임을 확인해 준다 — 판정 σ 변경은 불요.

## 4. E1 (정답지 대조 검출률) — 실측 라운드 절차

E1은 코드가 아니라 **데이터 문제**다: 클린 덤프에는 원리상 라벨이 없어 영구 SKIP이고, 그동안 오염 방어는 "pre-PM 구간이라 주입이 없다"는 가정이 진다. 개통 절차:

1. `scripts/dump_ae_input.py --scenario <스톰·드리프트> --suffix _e1round` — 주입 포함 덤프 생성 (라벨 = **기록 순번** `_wafer_idx`, C10 되짚기 금지 — 헌법 7장)
2. `build_clean_wafer_list.py alignment_check` — wafer 단위 라벨 정렬 검증 (평균 검사 금지 — 헌법 7장)
3. `validate_bundle --labels <injection_labels.csv>` — E1 활성 채점 (warmup 20 · min 30 · 판정 0.80)
4. 결과 3값: PASS / FAIL / **SKIP(표본<30 — 배포 불가)**

이 라운드는 e4 사후 검증이 아니라 **차기 challenger부터의 상시 절차**다. e4 소급 채점은 불가(e4 학습창에 주입 run이 없음) — 그 사실 자체를 승인 브리프의 잔여 리스크로 유지한다.
