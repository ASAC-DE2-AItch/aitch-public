# AITCH 제품 기획과 요구사항 변경 기록

AITCH는 반도체 식각 공정의 이상 신호를 분석하고, 엔지니어가 근거를 검토해 조치를 결정하도록 돕는 교육 팀 프로젝트입니다. 이 문서는 PM/PO의 문제 정의, 조사 자료 해석, 기능 우선순위, 요구사항 변경과 협업 방식을 보여주기 위해 원본 기획서 v4.2~v4.5를 공개용으로 편집한 자료의 안내입니다.

**공개 편집일: 2026-10-25.** 프로젝트는 2026년 6~8월에 진행했습니다. 아래 파일은 당시 작성한 기획 자료를 바탕으로 이번에 편집한 문서이며, 당시 Git 커밋이나 원문 전체를 그대로 공개한 것이 아닙니다.

## 조사와 기획 산출물

원문에는 프로젝트 배경, 기능 비교표, Must/Should/Could/Won't 범위, 단계별 실행 계획, 성공 지표, 위험과 가정, 예외 처리 정책이 있습니다. 보완 페르소나 문서에는 공개 현직자 인터뷰, 학술 연구, 업계 자료와 제품 자료를 참고한 사용자 유형과 불편 항목이 정리돼 있습니다.

페르소나는 문헌과 공개 자료를 바탕으로 합성한 기획 도구입니다. 네 명의 실제 사용자를 직접 인터뷰했다는 뜻이 아니며, 예시 이름과 대화문은 이 공개본에 싣지 않았습니다. 현업 멘토 피드백과 문헌 기반 가설도 구분합니다.

| 확인 또는 검토한 문제 | 기능과 정책에 연결한 내용 |
|---|---|
| 여러 알람을 건별로 확인해야 하는 부담 | 관련 알람을 사건 단위로 묶고 승인 요청을 관리 |
| AI 제안의 근거를 확인하기 어려움 | 모델 설명, 통계 상태, 과거 유사 사례를 함께 제시 |
| 정비 뒤 달라진 상태를 기존 기준으로 평가하는 문제 | 정상 여부 확인과 관리 기준선 변경, 모델 갱신을 구분 |
| 조치 후 해결 여부가 불분명함 | 승인과 실행 이후 효과 확인 상태를 별도로 정의 |
| 잘못 해석한 현업 요구가 기능을 과도하게 제한함 | 재확인 결과에 따라 제외 기능과 승인 경계를 정정 |

## 경쟁 비교와 정량적 기대효과

기획 당시 검증한 경쟁 비교와 기대효과는 PM/PO 판단의 근거입니다. [출처 대조와 경쟁 비교 기록](evidence-review-2026-10-25.md)에 원문 비교표, 확인된 연구 수치, 프로젝트 목표와 현재 공식 자료 대조를 함께 정리했습니다. 기대효과를 실제 실적과 구분한다는 이유로 조사 근거 자체를 삭제하지 않습니다.

서울대 논문의 가성 인터락 약 86%, IJSRM 논문의 가성알람 40% 이상 감소, KLA 비용 예시의 약 2,100만 달러는 원문에서 확인됩니다. 각 값에는 표본과 적용 조건이 있으므로 그 조건과 함께 사용합니다. 검색 30분에서 1분 이내 등의 수치는 기획 목표와 기대 시나리오로 표시합니다.

작성자가 당시 검증한 경쟁 비교표는 시점이 있는 조사 기록으로 보존했습니다. 현재 공식 자료의 기능 설명과는 구분합니다. AITCH가 교육 환경에서 검증하려 한 통합 지점은 **이상 탐지, 근거 제시, 조치 선택, 사람 승인과 효과 확인을 연결하는 설계**입니다.

## PM/PO 담당과 팀 결과

윤준호는 PM/PO로 기획서, 요구사항과 계약 관리, 역할 및 개발 범위 조율을 맡았습니다. 시뮬레이터, 승인 인프라와 사건 처리, 관제 화면의 구현 및 팀 코드 통합도 담당했습니다. 분석 모델, 통계 처리, 검색과 AI 분석 등은 팀원이 담당한 부분과 함께 서비스로 연결했습니다. 전체 플랫폼을 개인 단독 개발 성과로 표현하지 않습니다.

기획서의 범위와 성공 기준은 **계획**입니다. 이후 구현 및 시연 결과와 동일시하지 않습니다. 팀은 교육 시뮬레이션과 AWS 배포 환경에서 시연했으며 실제 생산라인을 운영하지 않았습니다. 실제 공장의 수율, 비용, 작업시간 개선을 달성했다고 주장하지 않습니다. 현재 구현 구조는 [저장소 README](../../README.md)를 함께 참고하십시오.

## 공개 편집 범위

공개본에는 문제와 판단, 변경 이유, 사용자 흐름, 우선순위, 수용 기준과 위험 관리 내용을 남겼습니다.

다음 내용은 이 문서 묶음에서 제외하거나 일반화했습니다.

- 멘토 및 팀원의 개인 정보, 직접 발언과 구체적인 현업 내부 운영 정보
- 제공 데이터의 원본 값, 익명 컬럼 매핑, 파일명과 세부 공정 파라미터
- 내부 API와 도구의 호출 규격, 이벤트 및 DB 스키마, 실행 코드와 프롬프트
- 계정, 접속 주소, 인증 정보, 인프라 식별자 및 배포 설정
- 예시 조치 결과를 실제 프로젝트 성과로 오해하게 하는 표현

경쟁 비교와 기대효과는 삭제 대신 출처, 조사 시점, 가정과 성과 귀속을 표시해 보존합니다. 첫 편집에서 충분히 대조하지 못한 이유로 이를 일괄 제외한 설명은 위 근거 검토 문서에서 정정했습니다.

원문 파일명에 붙은 버전을 기준으로 구분했습니다. 원문에 후속 보충 메모와 과거 표기가 함께 있는 부분은 공개본에서 해당 결정의 의미를 중심으로 정리했습니다. 이 편집본은 원문 전체나 실행 명세의 대체물이 아닙니다.
