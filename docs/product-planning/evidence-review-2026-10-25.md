# 경쟁 비교와 기대효과 근거 재검증

확인일: 2026-10-25. 대상은 기획서 v4.2~v4.5와 그 참고 자료에서 제시한 경쟁 기능 비교 및 정량적 기대효과입니다.

원문 작성자는 해당 비교와 수치를 기획 당시 검증했다고 재확인했습니다. 첫 공개 편집에서 현재 편집자가 출처를 충분히 대조하지 않은 상태로 일부를 제외한 것은 적절하지 않았습니다. 이 문서는 **기획 당시 조사 기록**, **현재 공식 자료의 확인 결과**, **외부 연구 수치**, **프로젝트의 목표 및 기대효과**를 각각 보존합니다.

아래 재검증은 문헌의 보고 내용을 확인한 것이며, 타 기관 실험을 독립적으로 재현하거나 AITCH의 실제 공장 성과를 증명한 것은 아닙니다. 현재 웹페이지로 과거 특정 시점의 제품 구성을 소급 단정하지 않습니다.

## 1. 확인된 정량 근거

| 항목 | 원문에서 확인한 내용 | 공개 문서에 사용할 범위 |
|---|---|---|
| FDC 가성 인터락 약 86% | 강신우의 서울대 2020년 논문은 식각 공정 일부 장비 그룹의 3개월 관측에서 해당 비율을 보고 | 특정 연구의 문제 규모를 설명하는 근거. 모든 팹의 평균이나 AITCH 입력 데이터 비율로 일반화하지 않음 |
| AI-SPC 가성알람 40% 이상 감소 | Parashare의 IJSRM 2025년 논문 초록에서 확인 | 외부 문헌의 개선 사례를 기획 기대효과의 참고 근거로 사용 |
| 수율 최대 1.7% 개선 및 MTTD 30% 이상 단축 | 같은 논문의 초록에 명시. 본문 사례 표의 수율은 93.5%에서 95.2%로 제시됨 | 해당 표의 차이는 1.7%p. 상대 개선율과 구분 |
| 미검출 이상에 따른 약 2,100만 달러 손실 | KLA-Tencor 소속 저자들의 2014년 원문 본문에서 확인 | 월 2만5천 장 투입, 수율 손실 25%, 말단 검사 약 30일 지연이라는 예시 조건을 함께 표시 |
| 사례 검색 30분에서 1분 이내, 처리 속도 30배 | 기획서의 As-Is/To-Be 기대효과 | 목표 시나리오로 복원. 30분과 1분을 가정한 비율은 30배이며 실제 달성 결과와 구분 |
| 정비 후 복구 3~5일에서 수 시간 이내 | 기획서의 기대효과 | 현업 검토와 기획 시점의 기대 시나리오로 보존. 전 산업의 평균이나 실제 시연의 실측값으로 바꾸지 않음 |
| 가성알람 35% 이상 감소와 미탐 0건 | 기획서의 수용 기준 | 평가 목표로 유지. 외부 논문의 40% 수치나 최종 실측 성과와 혼용하지 않음 |

### 서울대 논문의 분모

논문 PDF 17쪽(인쇄면 9쪽)에 86%가 명시되어 있고 PDF 34쪽(인쇄면 26쪽)의 표 3에는 수집 20,224건, 판독 제외 3,213건, 진성 2,359건, 가성 14,142건이 제시됩니다. 진성과 가성으로 제시된 건수의 비율은 약 85.7%입니다.

수집 총계와 제외 및 분류 건수의 합계는 표 안에서 완전히 맞지 않습니다. 따라서 '전체 20,224건 중 정확히 86%'라고 재계산한 값처럼 쓰지 않고, **논문에서 보고한 약 86%**로 인용합니다. 수치의 출처 자체는 확인됐습니다.

출처: [서울대 학위논문](https://s-space.snu.ac.kr/handle/10371/167128), [원문 PDF](https://s-space.snu.ac.kr/bitstream/10371/167128/1/000000159571.pdf).

### IJSRM 논문의 조건

초록과 본문 4장은 실제 상황에서 착안한 사례라는 설명을 사용합니다. 따라서 공개본은 '논문이 보고한 결과'로 소개하며, 모든 팹에서 검증된 보장치로 서술하지 않습니다. 외부 연구의 개선 수치와 AITCH의 실증 여부는 별개입니다.

출처: [논문 및 DOI](https://ijsrm.net/index.php/ijsrm/article/view/6439), [논문 PDF](https://ijsrm.net/index.php/ijsrm/article/view/6439/3986), DOI 10.18535/ijsrm/v13i06.ec07. 초록과 5.2.1절 참조.

### KLA 비용 예시의 조건

약 2,100만 달러는 본문의 월 2만5천 장, 수율 손실 25% 예시입니다. 같은 페이지의 그림 2는 월 10만 장과 손실 20%라는 다른 조건을 사용합니다. 본문 수치와 그래프 조건을 섞지 않습니다. 이 비용은 결함을 늦게 발견한 경우의 손실 추정이며 AITCH의 절감액이 아닙니다.

출처: David W. Price, Douglas G. Sutherland, “The Most Expensive Defect,” Solid State Technology, December 2014, 인쇄면 31~32쪽, [발행사 원문 PDF](https://www.semiconductor-digest.com/wp-content/uploads/2020/02/SST-Dec-2014.pdf).

## 2. 경쟁 비교표의 기획 당시 기록

다음은 v4.5에 남아 있는 당시 비교표의 표시를 텍스트로 보존한 것입니다. 작성자는 당시 검증을 완료했다고 확인했습니다. 아래 표는 **그 시점의 검토 기록**이며 현재 판매되는 모든 제품군의 기능 유무를 단정하는 표가 아닙니다.

| 비교 항목 | 원문 Applied Materials 표시 | 원문 TensorBlue 표시 | AITCH의 기획 방향 |
|---|---|---|---|
| FDC | 있음 | 있음 | 이상 감지 |
| SPC | 있음 | 있음 | 통계 분석 |
| R2R / APC | 자동 제어 | 자동 제어 | 사람 승인 후 적용 및 검증 |
| FDC 관리 기준선 능동 보정 제안 | 부분 | 없음 표시 | 기준선 재설정안 |
| RAG 지식 계층 | 없음 표시 | 없음 표시 | 유사 사례와 매뉴얼 검색 |
| 도구를 사용하는 AI Agent | 부분 | 없음 표시 | 분석 및 조치 지원 |
| 근거 카드 | 없음 표시 | 없음 표시 | 승인 자료에 근거 제시 |
| Human-in-the-Loop AI | 부분 | 없음 표시 | 승인 및 수정과 반려 |
| 승인 이력의 학습 활용 | 없음 표시 | 없음 표시 | 판단 이력의 축적 및 활용 |
| Open Source | 없음 표시 | 없음 표시 | 구현을 공개해 검토할 수 있는 참조 구조 |

당시 비교에 사용한 제품 버전과 웹페이지의 보존본은 이번 원문 묶음에 포함되지 않아, 현재 페이지와 달라진 시점은 이번 검토에서 독립적으로 확정하지 못했습니다. 이는 작성자가 당시 검증하지 않았다는 뜻이 아닙니다.

## 3. 현재 공식 자료와 대조한 결과

| 비교 항목 | Applied 공식 자료 | TensorBlue 공식 자료 | 현재 비교에서의 처리 |
|---|---|---|---|
| FDC, SPC와 R2R | 제품 목록과 기능 설명 확인 | FDC, 다변량 통계와 APC/R2R 설명 확인 | 기능 제공을 인정하고 통합 방식 비교 |
| RAG 및 지식 검색 | Genie의 검색 기반 제조 업무 지원 설명 | 제조 Copilot의 RAG 및 지식 검색 설명 | 현재 기준의 일괄 '없음' 표시를 수정 |
| 근거 제시 | 문서 참조를 통한 추적 가능성 설명 | 문서와 이벤트 출처 제시 설명 | AITCH 근거 카드와 정확히 같은 형식인지는 별도 비교 |
| 사람의 검토와 승인 | 승인된 레시피의 적용과 무단 변경 방지 설명. AITCH와 같은 AI 승인 흐름의 세부는 별도 확인 필요 | 중요한 결정의 사람 승인 및 감사 로그 명시 | '사람 개입이 없다'는 현재형 일반화를 피함 |
| 승인 이력의 추천 학습 활용 | 이번 공개 자료에서 구체적 방식 미확인 | 이번 공개 자료에서 구체적 방식 미확인 | 기록 보유와 학습 활용을 구분하며, 미확인을 부재로 표시하지 않음 |
| 특정 기준선 조정 및 도구 호출의 구현 | AITCH와 같은 상세 조건은 별도 확인 필요 | 동일 | 같은 이름이나 유사 기능과 동일 구현을 구분 |
| 소스 공개와 라이선스 | 제품별 범위 확인 필요 | 제품별 범위 확인 필요 | 웹페이지 미언급만으로 소스 공개 여부를 결론 내리지 않음 |

자료 범위:
- [Applied 제품군](https://appliedsmartfactory.com/process-quality-solutions/): SPC, Fault Detection, Run-to-Run Control, Recipe Management System, Knowledge Advisor.
- [Applied의 제조 RAG 설명](https://appliedsmartfactory.com/semiconductor-blog/ai-ml/retrieval-augmented-generation-in-semiconductor-manufacturing/): Genie와 문서 검색 기반 지원, 출처 추적.
- [TensorBlue 제조 플랫폼](https://tensorblue.com/industries/semiconductors): Module F, 출처 제시와 Human-in-the-Loop 항목.

현재 공식 자료는 공급자의 기능 설명을 확인하는 근거입니다. 실제 도입 성능이나 고객별 모든 구현을 독립 평가한 것은 아닙니다. 기획 당시의 차별화 검토는 보존하되, '현재 상용 솔루션에 전혀 없다'나 '시장에서 유일하다'는 문장은 이 현재 자료만으로 뒷받침하지 않습니다.

## 4. 기대효과와 검증 목표를 복원하는 방식

기대효과는 실적이 아니라는 이유로 삭제할 항목이 아닙니다. 출처와 가정, 목표 및 측정 방법을 붙여 기획의 사업적 판단으로 제시할 수 있습니다.

| 원문 항목 | 공개 문서에서의 위치 |
|---|---|
| 가성률 70%, AI-SPC 개선 38~46%라는 초기 표기 | v4.2의 초기 가정 이력으로 보존하고 후속 문서의 86%, 40% 이상 정정과 함께 읽음 |
| 연간 1,200시간 절감, 다운타임 60% 감소 | 초기 기획의 기대치로 보존. 대상 장비와 알람 수, 건당 확인시간, 운영일 및 기준시간에 따라 달라지는 산정값이므로 전체 산업 실측치로 제시하지 않음 |
| 30분에서 1분 이내의 검색 및 요약 | 기획 시나리오와 검증할 처리시간 목표 |
| 가성알람 감소 35%, 미탐 0건 | 시뮬레이션 수용 기준 |
| 실제 프로젝트 평가 및 배포 시연 | 그 결과에 대응하는 별도 증거로 설명 |

## 5. 공개 편집의 정정

첫 공개본의 '검증 근거가 부족해 수치를 덜어냈다'는 일괄 설명은 수정했습니다. 확인된 문헌 수치와 원문의 기대효과를 복원하고 출처 및 조건을 연결합니다. 원문 경쟁 표는 기획 당시 검토 기록으로 보존하며, 현재 기능 확인 결과는 별도 표로 제공합니다.

민감정보, 내부 API와 데이터 및 접속정보를 제외하는 공개 원칙은 유지합니다. 이번 보완은 조사와 판단의 근거를 되살리는 문서 수정입니다.
