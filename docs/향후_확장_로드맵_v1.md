## ⑤ 확장해도 안 넘는 선 — Won't-have 유지 (발표 Q&A 방어선)

- **완전 자동 Closed-Loop 제어** — Semi-Closed(HITL) 유지. 자동은 "가역 + 가드 + 회귀 조건" 3종 세트가 있을 때만.
- **Recipe 무승인 자동 반영** — v4.5 에서 Recipe R2R 은 서비스에 들어왔지만 이 선은 불변 (헌법 1-1).
- **실력치 이상 대응 자동 반영** — 진짜 이상을 기준선 이동으로 가리는 위험. 정기 리캘리(상한 내)만 자동.
- **LLM 의 제어 파라미터 직접 생성** — 수치는 통계 엔진, LLM 은 근거 문장만.
- CQRS/Event Sourcing · Safe RL supervisory — 복잡도/범위 초과.
