## 2. 시퀀스

### 2-1. 요지 (텍스트 압축본)

```
Phase2Signal(정착) ──┬─ [B] 재산정(500장) → R9 승인 요청 (Brief에 CT² 생성 동의 포함)
                     └─ [AE] 표본 창 확보 개시 (구현 = 되감기 예약 — 학습 X)
R9 반려 → provisional 유지 · CT² 미개시 (창 정보만 보존)
R9 승인 → firm 발행 → ChamberRequalified ──→ [CT² 오케스트레이터]
  ① 가드: 동의 승계 · converged(D8) · 챔버 스코프(선결) · 멱등(incident_id)
  ② 표본: 되감기(D9·D10) → 소급 필터(D6) → n ≥ ct2_min_train_wafers? 미달 시 전방 연장(D7 만료)
  ③ run_ct2 비동기(본선 격리) → challenger 번들(신규 stamp, 미배포) → 검증 리포트 → ct_decisions(shadow)
  ④ 배포 승인 요청(자동 검증 게이트) — 파생 thread <incident_id>-CT2 (D3·D4)
      승인 → deploy_bundle → consumer 관리형 리로드 + DriftTracker 리셋 → CHANGELOG·ct_decisions(promoted)
      반려 → challenger 보존·미배포 (재요청 = 엔지니어 발의)
```
